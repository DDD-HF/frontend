📋 프로젝트 환경
프론트엔드 프레임워크: React

언어: TypeScript

번들러/빌드 도구: Vite

패키지 관리자: npm

📥 브랜치 체크아웃
현재 프로젝트의 임시 초기 설정 브랜치로 전환합니다.

**git checkout initial_setting**

⚙️ 설치 및 실행 (Installation & Running)
프로젝트를 로컬 환경에서 실행하기 위한 단계별 안내입니다.

1. 의존성 설치
   프로젝트에 필요한 모든 패키지들을 설치

**npm install**

2. 개발 서버 실행
   설치가 완료 -> 다음 커맨드를 사용하여 개발 서버를 실행

**npm run dev**

3. 브라우저 접속
   개발 서버가 성공적으로 실행 -> 5173 포트로 접속

**http://localhost:5173**
